Platform details

A members platform that behaves like a bank vault.

One secure login, one admin, two access tiers, and a knowledge base that expands to any depth without ever getting messy. Here's how it works.

How it works

From login to knowledge in three steps.

1

Admin adds users

One admin account creates every member and assigns them a tier — Leadership or Employee. No self-signup, full control.

2

Members log in securely

Each member signs in over HTTPS with a strong, hashed password and a protected session. The right content loads for their tier.

3

Knowledge, on demand

They browse the accordion knowledge base — expanding only what they need. Admin edits any module's text, summaries and links at any time.

The knowledge base

17 modules. Infinite depth. Zero reloads.

Every module is a collapsible accordion that can nest subsections as deep as you like — three levels, ten, it stays tidy. Each layer holds text, summaries or links to studies. Try it on the right.

Security

Bank-grade by default.

Access rules aren't just hidden in the interface — they're enforced on the server, so an Employee simply cannot reach Leadership content, no matter what they try.

  • HTTPS everywhere. Every page encrypted in transit on both .dk and .com.
  • Hashed passwords. Strong password rules; nothing stored in plain text.
  • Server-side access control. Tier checks run on the backend for every request.
  • Protected sessions. Sessions expire and are guarded against common attacks.
  • One admin, full oversight. Add, remove and re-tier users from a single control point.
